# ServiceNow (NOW) research folder

The "de-rated quality compounder" leg of the Mag-7 / AI work. NOW is the cleanest
"is AI accretive or cannibalistic to a software incumbent?" battleground — same
question as Google/Search, but the stock has already fallen ~40% in a year, so the
de-rate is done and the question is whether the market is wrong.

Built the week after Q3 2026 (reported Oct 28 after close), which triggered a **−27%
one-day drop** (Oct 28 $150.13 → Oct 29 $109.67) and a slide to ~$102.

Note: NOW did a **5:1 stock split on Dec 18, 2025** — all prices here are post-split.

## Files
- `valuation-and-analyst-targets.md` — TIKR multiples (the big de-rate), TipRanks targets.
- `q3-2026-and-crpo-bridge.md` — the Q3 print + **the cRPO decomposition** (the whole debate).
- `sell-side-q3-reviews.md` — JPMorgan / TD Cowen / BofA synthesis + the skeptics.
- `earlier-2026-context.md` — Q1/Q2 calls, the May Financial Analyst Day 2030 targets, GS/Citi conferences, the McDermott thesis.
- `analysis-is-this-the-one.md` — the synthesis: is NOW the play, and where it breaks.
