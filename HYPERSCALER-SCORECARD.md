## Each name in one paragraph
- **GOOGL — the value + most-derated play.** Cheapest (17.8x), twice as derated (−35%), **net cash**,
  owns a **frontier model (Gemini) + the best cloud silicon (TPU)**, six monetization legs. The one risk
  (Search commercial-query monetization) is a single, trackable binary the share data currently
  contradicts. **Best risk/reward *if* Search holds.**
- **AMZN — the best cloud business.** AWS is bigger ($184B run-rate), higher-margin (39%), accelerating
  six straight quarters and guided **>40% both '27 & '28**; **own silicon (Trainium)** rivals TPU; retail
  + **$83B ads** cushion; FCF inflects first ('28). But net debt, priciest-ish, consumer cyclicality,
  only −14% off high. **Best business, fair-not-cheap entry.**
- **MSFT — the quality + safety play.** Highest margins (47% EBIT) and returns (27% ROIC), **lowest beta
  (1.04)**, **FCF-positive throughout**, and the **best enterprise-AI distribution (Copilot = OS for
  work)**. But the **priciest (15x EV/EBITDA), least derated (−13%), least vertically integrated** (leans
  on NVIDIA + OpenAI), and **most OpenAI-concentrated**. **Safest business, worst value, real concentration risk.**

## The honest rankings (depends on the criterion)

**For your slot — value + balance sheet + most-derated-vs-fundamentals + a single trackable risk:**
1. **GOOGL** — cheapest, most derated, net cash, frontier model + silicon, one trackable risk.
2. **AMZN** — best cloud + own silicon + diversified; add on a dip (only −14% off high, net debt).
3. **MSFT** — highest quality but priced for it; buy on a flush, not at the high; OpenAI concentration.

**For "best AI *business*":** AMZN ≈ MSFT > GOOGL (AWS scale + Azure quality; Google Cloud faster but
lumpier/smaller). **For "safest / lowest-beta ballast":** MSFT > GOOGL > AMZN. **For "cheapest / most
upside":** GOOGL > AMZN > MSFT. **For "own-silicon / NVDA-hedge":** GOOGL ≈ AMZN >> MSFT.

## The cleanest way to play it
**Own GOOGL + AMZN as the hyperscaler core; treat MSFT as a quality name to add only on a pullback.**
- **GOOGL = the larger starter** (value, net cash, most derated, frontier model + TPU). Scale in here,
  add toward $230–240.
- **AMZN = the business-momentum leg** (best cloud + Trainium + ads/retail), added on weakness toward the
  low-$200s.
- **MSFT = the quality ballast on a flush** — superb business, but at −13% and 15x EV/EBITDA you're paying
  full freight with the most concentrated single-customer (OpenAI) risk. Wait for low-$400s / ~12x
  EV/EBITDA.
- Together they share the backlog-floored demand ($561B/$578B/$677B) and hedge each other's main risks
  (Search / consumer / OpenAI). This is the diversified, self-funded "long AI demand" core — the clean
  wrapper from `00-THESIS-why-hyperscalers.md` — against a small **NVDA torque stub**.

## The correction to the running thesis (confirmed across all three)
"Own-silicon / un-scarce-the-NVDA-shovel" is a **GOOGL + AMZN** story, not unique to either, and **MSFT
is the laggard** there (Maia is real but behind). So the NVDA-hedge leg of the barbell is best expressed
through **GOOGL and AMZN**; MSFT is the quality/distribution play, more *dependent* on NVIDIA + OpenAI,
not a hedge against them.
