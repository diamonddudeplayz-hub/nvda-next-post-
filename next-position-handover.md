## The framework (the lens, built this session)
- **The barbell.** (a) Sizing: keep a core + cut concentration — survive being wrong on
  timing, still catch the melt-up. (b) Cross-asset: long the AI-*demand* beneficiaries that
  win as the **scarcity premium breaks** (buyers/own-silicon, cash-gen software, grid/power)
  vs trim the **shovels** whose moat is scarcity (NVDA, memory, neoclouds). Same factor,
  opposite exposure.
- **The Adobe lesson (governing rule).** Avoid the **catalyst-less value trap**. You can't
  time when the market changes its mind — a *sentiment* catalyst = dead money. Need **cheap +
  a dated forcing function.**
- **Catalyst-hardness ranking (the sorting tool):**
  - BEST: inflection **already in the numbers** + a dated event → **Itron**.
  - MIDDLE: semi-dated (scheduled guide + a backlog that must convert) but the inflection is
    still a *promise* → **Xylem**.
  - WORST: **undated sentiment** catalyst ("re-rates when the market stops pricing it as X")
    → **Adobe, ServiceNow**.
- **"Govern-the-exhaust" meta-trade:** more AI output → more need to govern/track/manage it.
  Adobe-enterprise (AEP), ServiceNow (agents), security/data. One trade, rank by asset-floor +
  catalyst-hardness.
- **AI-disruption-resistance test** (what's AI-proof): proprietary data / mandated standard
  (S&P, Moody's, **FICO**), security (attack surface explodes with agents), mission-critical/
  deterministic, "more AI = more of my product." Grid/power/physical-infra is disruption-proof
  in the software sense.
- **Insulated vs asymmetric tension:** the most insulated names (regulated utes, water, data
  monopolies) rarely get cheap-with-a-catalyst; the asymmetry lives in **smaller-cap,
  mispriced-by-category** names (Itron). Decide which you're optimizing each time.

## The checklist (apply to every new candidate)
1. **Short-term (why NOW):** catalyst on the calendar or already printing? Rank hardness (printing > dated event > undated sentiment).
2. **Laggard or already-run?** YTD vs the theme; near 52-wk low = good; up 60%+ = crowded.
3. **Valuation:** cheap vs own history AND peers; reverse the multiple (what's priced in).
4. **Long-term:** secular/non-discretionary demand? AI-disruption-resistant? moat (data/standard/switching cost/network)?
5. **Asset floor / downside:** sum-of-parts? recurring revenue? is it already near the bear-case price?
6. **Trap check:** cheap because *mispriced* (opportunity) or cheap because *deteriorating* (trap)? Landis-test = rev declining + losses = trap.
7. **Insulation vs asymmetry:** which is this, and which am I optimizing?
