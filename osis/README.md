## One-line verdict
Clears the bar on *both* halves (dated-ish short-term catalyst via backlog + 2H prints; durable
AI-proof long-term moat), with the honest caveat that the catalyst is **backlog-conversion
(semi-dated), not earnings-already-printing** — Q1's beat was buyback-flattered. Entry is good
*because* the ~40% de-rate (34x → 17x) already happened. **Make-or-break = the April Q3 FY27 print.**
